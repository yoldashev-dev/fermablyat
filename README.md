# 🌾 AgroTycoon 3D: Земля и Техника (RTX Edition)

> Высокотехнологичный 3D-симулятор агрохолдинга прямо в браузере. Развивайте ферму, управляйте техникой, перерабатывайте урожай на мельнице, разводите скот и выполняйте контракты!

## 🌟 Ключевые особенности

- **🎮 Два режима игры**:
  - **🛰️ Стратегия (RTS)**: управление фермой с высоты птичьего полёта, покупка земель, наём рабочих, строительство.
  - **👨‍🌾 Вид от первого лица (FPS)**: вселение в человечка-фермера, ходьба ногами по полям (`WASD`), обзор мышью без инерции, ручная обработка полей.
  - **👤 Переключение перспективы (`C`)**: вид от 1-го лица (из глаз) или от 3-го лица (со спины).
- **🚜 Управление техникой**:
  - Садитесь за руль тракторов и комбайнов (`WASD`), пашите и собирайте урожай.
  - Расход дизельного топлива, датчик бака и клубы пыли из-под колёс.
- **🏭 Производственные цепочки и Животноводство**:
  - **Ветряная мельница**: перемалывает пшеницу в муку высшего сорта (+180% прибыли).
  - **Коровник**: стадо коров даёт свежее молоко на продажу и органический навоз для 100% восстановления почвы.
- **🌱 Хардкорная агрономия**:
  - Истощение почвы при монокультуре (-25% плодородия).
  - Бонус за севооборот (+10% плодородия при смене культур).
  - Коммерческие контракты со сроками поставки и премиями до +45%.
- **✨ Ultra 3D Графика**:
  - Динамическая смена дня и ночи с мягкими тенями (PCFSoftShadowMap).
  - Процедурные PBR-материалы почвы, дерева и металла.
  - Ветер и колыхание посевов на ветру.
  - Лесополоса вокруг карты (110 сосен и берёз через `InstancedMesh` — стабильные 60 FPS).
  - Бескрайняя зелёная долина с холмами на горизонте.

## ⌨️ Управление

| Действие | Клавиши |
|---|---|
| Вселиться в фермера / Режим стратегии | `V` или клик по человечку |
| Движение фермера / Езда на технике | `W`, `A`, `S`, `D` (или русские `Ц`, `Ф`, `Ы`, `В`) |
| Бег (Спринт) | `Shift` |
| Переключение вида 1-е / 3-е лицо | `C` |
| Взаимодействие / Работа инструментом | `ЛКМ` (Левая кнопка мыши) |
| Выбор инструментов (1–5) | `1` Мотыга, `2` Лейка, `3` Семена, `4` Коса, `5` Удобрения |
| Выйти из техники | `E` или `ESC` |

## 🚀 Развёртывание на Vercel

Проект полностью готов для мгновенного развёртывания на **Vercel**:

1. Загрузите репозиторий на GitHub: `https://github.com/yoldashev-dev/fermablyat.git`
2. Перейдите на [Vercel](https://vercel.com) и нажмите **"Add New Project"**.
3. Выберите репозиторий `fermablyat`.
4. Нажмите **"Deploy"** (настройки сборки не требуются, это чистый HTML5/WebGL).
5. Игра сразу доступна онлайн!
